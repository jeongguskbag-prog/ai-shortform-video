ai-shortform-video (Windows 실행 파일)
=====================================

대본을 넣으면 나레이션·자막·사진이 들어간 세로 쇼츠 영상을 만들어 주는 프로그램입니다.
Python이나 FFmpeg를 따로 설치할 필요가 없습니다.


처음 실행하기
------------
1. 이 폴더를 원하는 곳(예: 문서 폴더)에 그대로 둡니다. 폴더 안의 파일을 따로 옮기지 마세요.
2. ai-shortform-video.exe 를 더블클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누르세요.
     (디지털 서명이 없는 프로그램이라 처음 한 번 나오는 경고입니다.)
3. 처음에는 메모장으로 .env 파일이 열립니다.
   GEMINI_API_KEY=your_gemini_api_key_here
   줄에서 your_gemini_api_key_here 를 지우고 Gemini 키를 붙여 넣은 뒤 저장(Ctrl+S)하세요.
   키 발급: https://aistudio.google.com/apikey
4. ai-shortform-video.exe 를 다시 실행하면 브라우저가 자동으로 열립니다.


사용하기
-------
- 브라우저에 대본을 넣고 [영상 만들기]를 누르세요.
- 브라우저가 열리지 않으면 검은 창에 나온 주소(예: http://127.0.0.1:8000)를 직접 여세요.
- 검은 창은 프로그램 본체입니다. 영상을 만드는 동안 닫지 마세요.
- 끝내려면 검은 창을 닫으면 됩니다.
- 만든 영상 파일은 이 폴더의 output 폴더에 저장됩니다.


사진 (선택)
----------
- 무료 등급 Gemini 키는 AI 이미지를 만들 수 없어서, 대신 무료 사진(Openverse)을 자동으로 넣습니다.
- Pixabay 키(https://pixabay.com/api/docs/, 가입 후 바로 발급)를 .env 의 PIXABAY_API_KEY= 뒤에 넣으면
  사진 선택지가 늘어납니다.
- 사진 출처는 영상 아래에 표시됩니다. 영상을 올릴 때 설명란에도 적어 주세요.


새 버전으로 바꾸기
----------------
새 zip을 받아 압축을 푼 뒤, 예전 폴더의 .env 파일(과 필요하면 output 폴더)을 새 폴더로 복사하세요.
